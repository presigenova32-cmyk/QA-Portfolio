# Manual QA Testing Portfolio

Welcome to my QA Portfolio repository! This project contains all test artifacts, bug reports, and API testing collections for both Web and Mobile applications.

---

## 📌 Projects Included

### 1. Web E-Commerce Testing (SauceDemo)
- **Scope:** E-commerce UI/UX functionality, checkout flow, and edge cases.
- **API Tests:** ReqRes endpoints (`GET`, `POST`, `DELETE`) for user management.
- **Repository File:** `SauceDemo.json`

### 2. Mobile Application Testing (Spotify)
- **Scope:** Mobile-specific testing (Screen orientation, System interrupts, Network resilience, and Biometric auth).
- **API Tests:** Spotify Web API endpoints (`GET`, `POST`).
- **Repository File:** `Spotify API Testing.json`
